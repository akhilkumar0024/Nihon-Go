# Nipp-ON — Project Context & Developer Reference

> **Quick Summary**: This document captures the complete architectural, design, algorithmic, and operational context for the **Nipp-ON** project (stored in repository `Nihon-Go`). Read this file at the start of any new session or chat to immediately understand the system state, decisions, and patterns.

---

## 1. Project Overview & Identity

* **Project Name**: Nipp-ON (Repository: `Nihon-Go`)
* **Brand In-App**: Nipp-ON (JLPT N5 Japanese Language Learning Companion)
* **Objective**: A high-fidelity, production-quality AI vocabulary learning application built to demonstrate product thinking, practical generative AI integration (Google Gemini), Web Speech audio capabilities, and strict adherence to Google Stitch UI designs.
* **Git Repository**: `https://github.com/akhilkumar0024/Nihon-Go.git` (`branch: main`)

---

## 2. Tech Stack & Environment

* **Frontend**: React 18, TypeScript (`strict` mode), Vite 8, Tailwind CSS v3 with custom design tokens.
* **Typography**: Google Fonts — `Plus Jakarta Sans` (UI / English body), `Noto Serif JP` (Kanji & Japanese hero typography), `Material Symbols Outlined` (Google Icons).
* **Styling Paradigm**: Google Stitch Material 3 design tokens configured in `tailwind.config.js`:
  * Primary: Pine Forest Green (`#013628`)
  * Secondary / Accent: Terracotta Earth (`#97472E`)
  * Surface tokens: `surface-container-lowest`, `surface-container-low`, `surface`, `surface-container`, `surface-container-high`, `surface-bright`.
* **Backend / API**: Vercel Serverless Functions (`/api/*.ts`) using Node runtime, zero external heavy dependencies.
* **AI Provider**: Google Gemini API via native `fetch` in `/api/_gemini.ts`.
* **Local Dev Server**: Runs on `http://localhost:5173/` (`npm run dev`).

## 3. Core Features & Screen Structure

1. **Dashboard (`DashboardScreen.tsx`)**:
   * Hero banner with daily JLPT N5 milestone progress (20%), 1-Day Streak, active Daily Goal (5/5 words).
   * Daily Flashcard Review with audio playback and study drawer quick-actions.
   * Recent practice activity log and quick navigation buttons.

2. **Vocabulary Search & Word Detail (`VocabularyScreen.tsx`)**:
   * English/Romaji/Japanese search bar with live voice input (Web Speech Recognition).
   * Rich Kanji Card: Kanji character, Furigana reading, Romaji, English definition, JLPT badge, Part of Speech, Pitch Accent notation (e.g. `Heiban [0]`, `Atamadaka [1]`).
   * Native Audio player with adjustable speeds (0.75x, 1.0x, 1.25x).
   * Contextual Example sentences with Japanese, Romaji, and English translation.
   * Cultural nuance and usage notes generated by Gemini AI with curated fallbacks.
   * "Add to Practice Notebook" with duplicate detection.

3. **AI Sensei Tutor (`TutorScreen.tsx`)**:
   * Split-pane conversational tutor:
     * Left pane (35%): Anchored word context card with interactive quick prompts ("How to use in formal restaurant?", "Explain honorifics", "Quiz me on conjugations").
     * Right pane (65%): Message stream retaining context of the current word.
   * Markdown formatting parser rendering `**bold**`, `*italic*`, and bullet points into styled semantic elements.
   * "Listen Pronunciation" inline audio button on tutor responses.
   * Voice input via microphone button for speaking questions to the tutor.

4. **Practice Notebook & Quiz (`PracticeNotebookScreen.tsx`)**:
   * Dual-mode interface: Interactive Practice Session vs. Saved Words Notebook.
   * Practice Quiz: 4-option multiple-choice tests on kanji readings, definitions, and contextual sentences.
   * Instant feedback drawer on answer selection: Explains grammar, awards +15 XP, and updates progress metrics.
   * Saved Notebook: Filtering by JLPT level and mastery status, word deletion, and audio playback.

5. **Audio Settings Modal (`AudioSettingsModal.tsx`)**:
   * Selection of system Japanese TTS voices (`ja-JP`).
   * Pitch and playback rate sliders with a test playback phrase.

## 4. Key Architectural Decisions & Solved Gotchas

### A. Japanese Kanji vs. Furigana TTS Pronunciation
* **Issue**: Kanji characters like `水` (water) have multiple readings (Kun'yomi `mizu` vs. On'yomi `sui`). Passing bare kanji `水` to `SpeechSynthesisUtterance` causes browsers to default to the On'yomi reading *"sui"*.
* **Solution**: Always pass the Hiragana reading `word.hiragana || word.japanese` to `audioService.speakJapanese()`. This guarantees the synthesizer speaks *"mizu"*.

### B. Markdown Formatting & Speech Synthesis Collision
* **Issue**: Gemini tutor responses contain Markdown bold (`**水**`) and italics. In unparsed text bubbles, literal asterisks `**` were shown to the user, and clicking audio playback caused the speech engine to read *"asterisk asterisk"* verbatim.
* **Solution**:
  1. `TutorScreen.tsx` implements `renderFormattedChatMessage()` with `parseInlineMarkdown()`: Transforms `**bold**` into `<strong className="font-bold text-primary">`, `*italic*` into `<em>`, and lists into structured bullet elements.
  2. `audioService.speakJapanese()` in `src/services/audio.ts` automatically strips all formatting characters (`*`, `_`, `#`, `` ` ``, `~`) before speech synthesis.
  3. In `TutorScreen.tsx`, `handlePlayJapaneseInChat()` isolates only Japanese vocabulary characters via regex (`[\u3040-\u309F\u30A0-\u30FF\u4E00-\u9FAF]...`) so the audio only speaks the target Japanese words rather than entire English paragraphs.

### C. Noun vs. Verb Nuance in AI Fallbacks
* **Issue**: The fallback response for restaurant queries previously assumed words were verbs and appended `ます` (e.g. `水` -> `水ます`).
* **Solution**: `api/tutor.ts` checks `isVerb`. For nouns like `水`, it explains the polite prefix `お水 (omizu)` and sample restaurant phrase `「お水を一杯ください」`.

### D. Navigation Layout Clearance
* **Issue**: Fixed `TopNavBar` has a height of `h-16` (`4rem`). Using `pt-16` on `<main>` could be overridden by nested Tailwind padding shorthands.
* **Solution**: In `src/App.tsx`, `<main>` uses `mt-16 min-h-[calc(100vh-4rem)]`, ensuring all screens have guaranteed clearance under the top navigation bar.

### E. API Key Security & Fallback Strategy
* **Architecture**: The Gemini API key (`GEMINI_API_KEY`) is stored strictly on the server in `.env` / Vercel environment variables and is never prefixed with `VITE_` or exposed in client bundles.
* **Graceful Degradation**: Both `/api/vocabulary` and `/api/tutor` have comprehensive built-in curated datasets. If the Gemini API key is unset, rate-limited, or times out, the app continues to function seamlessly with curated pedagogical fallbacks.

## 7. Working Rules for Future Chats

1. **Keep Aesthetics Premium**: Strictly maintain the Google Stitch design language (Noto Serif JP headers, Plus Jakarta Sans body, Pine Forest `#013628`, Terracotta `#97472E`).
2. **Never Expose API Keys in Client Bundles**: Any external AI calls must route through `/api/` endpoints.
3. **Audio Integrity**: When passing text to `audioService.speakJapanese()`, always pass clean Hiragana readings for standalone words, and ensure markdown symbols are sanitized.
4. **Preserve User Data**: Notebook state and quiz history should continue to be saved to `localStorage`.
